# Text-Based-Image-Generator-with-neural-style-transformation
A diffusion-based text-to-image generator with multilingual input support, artistic style transfer, and post-processing enhancements. Allows users to generate stylized images from text prompts in multiple languages with improved quality and flexibility.


Text-to-Image Generation with Multilingual and Artistic Control
This project implements a diffusion-based text-to-image generation system enhanced with multilingual support and neural style transfer. Users can input prompts in various languages, which are automatically translated to English for processing. The system allows artistic customization of images through style transfer and includes post-processing features like contrast adjustment and sharpening for improved clarity. Designed for both creativity and accessibility, the project showcases a customizable and inclusive approach to AI-driven image synthesis.
